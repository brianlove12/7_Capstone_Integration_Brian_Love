5. JavaScript code defense

Explain initialization, state synchronization, activation, and Escape/focus behavior in your own words. Refer to the exact variable, attribute, dataset value, function, and event used.

The button variable selects the element with the .menu-button class, and the list variable selects the navigation list with the #primary-nav ID. The script adds the js class to the HTML element so the CSS knows that JavaScript is available. It then reveals the Menu button and initializes the navigation with data-open="false".

The named setMenuState() function keeps the menu states synchronized. It changes the button's aria-expanded attribute and the navigation list's data-open value to either true or false. The CSS uses the data-open value to determine whether the navigation list is visible at narrow widths.

The click event checks the current value of aria-expanded and passes the opposite value to setMenuState(). Because the control is a native button, the browser already provides mouse, Enter, and Space activation without additional keyboard code.

The keydown event checks whether the Escape key was pressed while the menu is open. If it was, setMenuState(false) closes the menu and button.focus() returns keyboard focus to the Menu button.
