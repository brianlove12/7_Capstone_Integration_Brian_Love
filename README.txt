MODULE 5 RESPONSIVE NAVIGATION DELIVERABLE STARTER

TELEPATHIC RACE RESPONSIVE NAVIGATION

Site Name:
Telepathic Race

Purpose:
Telepathic Race is an educational site featuring workshops and resources
that explore the Ten Spiritual Vibrations.

Navigation:
The responsive primary navigation contains six destinations:
Home, Ten Vibrations, Workshops, Visit, Events, and Get Support.

The navigation uses a mobile-first layout. At narrow widths, JavaScript
progressively enhances the navigation with a Menu button. At wide widths,
the complete navigation remains visible.

Included Files:
- index.html
- visit.html
- support.html
- styles.css
- navigation.js
- navigation-plan.html
- README.txt
- narrow-menu-open.png
- keyboard-focus.png

Testing:
Open index.html, visit.html, and support.html in a web browser.

At narrow widths, use the Menu button with a pointer, Enter, and Space.
Press Escape while the menu is open to confirm that the menu closes and
focus returns to the Menu button.

The project was tested at 320 CSS pixels, around the breakpoint, at 200%
browser zoom, and with temporary long navigation labels. JavaScript and CSS
were also disabled separately to test failure behavior. Wide-layout recovery
was tested after closing the narrow menu.

Breakpoint:
The horizontal navigation began to become jumbled at approximately 590px.
A content-based breakpoint of 40em was selected to provide additional space
before switching to the wide horizontal layout.

Assets:
narrow-menu-open.png documents the open narrow navigation.
keyboard-focus.png documents the visible keyboard focus indicator.

Paths:
All HTML, CSS, JavaScript, and image references use relative paths.
